BACKTEST — Simulated, not live trades. Runs the exact live strategy over historical data. Read-only; nothing is traded and the live ledger is never touched.
Run a Backtest
Set a Split date to run TRAIN (start → split) and VALIDATION (split → end) back-to-back with identical settings, then compare. Leave it blank for a single full-range backtest.
Tune on TRAIN, confirm on VALIDATION — if it works on TRAIN but fails on VALIDATION, it was overfitting. First run fetches history with a 12s rate-limit delay between calls (a few minutes); results are cached so re-runs are instant.
